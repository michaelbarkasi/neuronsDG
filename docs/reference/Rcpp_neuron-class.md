# The neuron reference class

`Rcpp_neuron` is the S4 reference class that Rcpp Modules generates for
every neuron object (its own parent class, `C++Object`, is likewise
generated by Rcpp itself and is not specific to this package). Users
should never call `new("Rcpp_neuron", ...)` directly; construct neuron
objects with
[`new.neuron`](https://michaelbarkasi.github.io/neuronsDG/reference/new.neuron.md)
or
[`load.rasters.as.neurons`](https://michaelbarkasi.github.io/neuronsDG/reference/load.rasters.as.neurons.md)
instead, and see
[`neuron-methods`](https://michaelbarkasi.github.io/neuronsDG/reference/neuron-methods.md)
for the `print`/`summary`/`plot` methods defined on this class.
