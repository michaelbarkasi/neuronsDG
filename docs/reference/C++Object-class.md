# Rcpp's generic C++ object base class

`C++Object` is the S4 reference class that Rcpp Modules generates as the
common parent of every Rcpp Modules reference class, including this
package's own
[`Rcpp_neuron`](https://michaelbarkasi.github.io/neuronsDG/reference/Rcpp_neuron-class.md).
It is generated by Rcpp itself, not by neuronsDG, and carries no
behavior or documentation specific to this package; it is documented
here only because every exported S4 class, including inherited ones that
happen to be reachable this way, needs a documentation entry for CRAN's
checks. There is no reason for a user of neuronsDG to reference
`C++Object` directly.
